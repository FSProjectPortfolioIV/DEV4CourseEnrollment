# DEV4 Course Enrollment Repository

Welcome to **Project and Portfolio: Development IV**.

This repository is how you claim your personal, private workspace for the course. You only need to do this **once**. The repository you get here is yours for the whole course.

---

### What you need
The **course code**, found in your FSO assignment.

---

### How to get your repository

1. Click the **[Issues](../../issues)** tab at the top of this page.
2. Click **New issue**.
3. Next to **Request Assignment Repository**, click **Get started**.
   *(Do not use "Open a blank issue", a blank issue will not work.)*
4. Paste the course code into the **Course Code** box.
5. Click **Create**.

That's it. Now wait a few minutes.

---

### What happens next

The system will reply to your issue as it works:

1. "Verification passed" means your code was accepted and your repository is being built.
2. An invitation email from GitHub asking you to collaborate on your new repository.
You must **open that email and accept the invitation** or you will not be able to see your repository.
3. A **link to your repository**, then the issue closes automatically.

Your repository will be named `dev4-` followed by your GitHub username, for example
`dev4-JohnDoe`. It is **private**, only you and the instructor can see it.

> The bot's comments are automatically cleaned up about 30 minutes after the issue closes. **Save the repository link** (or just accept the email invitation, which is the reliable way back to it).

---

### FAQ Troubleshooting

**"The course code you entered is incorrect"**
Check the code in FSO and re-enter it exactly. It is **case-sensitive**, and stray spaces or a partial copy-paste will fail. Open a new issue to try again.

**"You already have an assignment repository"**
You are already set up. The comment includes the link to your existing repository, use that one. Do not try to create a second. If you are a retake, then please continue where you left off.

**Nothing happens at all after submitting**
You most likely opened a *blank* issue instead of using the **Request Assignment Repository** template. Close it and start again from step 3 above.

**You never got the invitation email**
Check spam. You can also see pending invitations at [github.com/notifications](https://github.com/notifications) or by going directly to `https://github.com/FSProjectPortfolioIV/dev4-yourusername` while signed in.

**Anything else?** Please contact your instructor.
